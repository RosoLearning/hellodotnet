# hellodotnet

basic dotnet app via backstage

A minimal .NET 10 Web API scaffolded by Backstage.

## Run locally

Install the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0), then run:

```sh
dotnet run
```

The application exposes:

- `GET /` - service name, description, and status
- `GET /health` - health status
